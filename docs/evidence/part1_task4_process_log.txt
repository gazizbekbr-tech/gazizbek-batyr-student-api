==================== Difference between > and >> ====================

batyr@gazizbek-batyr-linux:gazizbek-batyr-student-api$ echo 'first line'  > /tmp/redirect_demo_gazizbek.txt

batyr@gazizbek-batyr-linux:gazizbek-batyr-student-api$ echo 'second line' > /tmp/redirect_demo_gazizbek.txt

batyr@gazizbek-batyr-linux:gazizbek-batyr-student-api$ cat /tmp/redirect_demo_gazizbek.txt    # > overwrote the file, only the last line is left
second line

batyr@gazizbek-batyr-linux:gazizbek-batyr-student-api$ echo 'third line' >> /tmp/redirect_demo_gazizbek.txt

batyr@gazizbek-batyr-linux:gazizbek-batyr-student-api$ cat /tmp/redirect_demo_gazizbek.txt    # >> appended to the end of the file
second line
third line

batyr@gazizbek-batyr-linux:gazizbek-batyr-student-api$ cat >> logs/Gazizbek_Batyr_log_analysis.txt <<'TXT'

Difference between > and >> (Batyr Gazizbek):
  >   redirects command output to a file and OVERWRITES it (the file is truncated
      first or created if it does not exist).
  >>  redirects command output to a file and APPENDS it to the end, the old
      content is kept. That is why the system report script uses tee -a (append)
      and the log keeps every run, while 'echo ... > file' started this analysis
      file from scratch.
TXT
